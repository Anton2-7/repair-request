# Сервис приема заявок на ремонт

FullStack приложение для управления заявками на ремонт с ролями диспетчера и мастера. Разработано в рамках тестового задания.

## 📋 Функциональность

### Роли пользователей
- **Диспетчер**: управление всеми заявками, назначение мастеров, отмена, архивация
- **Мастер**: просмотр назначенных заявок, взятие в работу, завершение

### Управление заявками
- ✅ Создание заявок (клиент, телефон, адрес, описание)
- 📋 Просмотр списка заявок с фильтрацией по статусу
- 🔍 Поиск по клиенту, телефону, адресу
- 👤 Назначение мастера на заявку (диспетчер)
- 🚫 Отмена заявки (диспетчер)
- ▶️ Взятие в работу (мастер)
- ✅ Завершение заявки (мастер)
- 📦 Архивация выполненных/отмененных заявок
- 🔄 Восстановление из архива

### Защита от гонок
- 🔒 Атомарная операция при взятии заявки в работу
- 📊 При параллельных запросах только один успешен, остальные получают 409 Conflict

## 🛠 Технологии

- **Backend**: Node.js + Express
- **Database**: SQLite (с атомарными операциями)
- **Frontend**: Чистый HTML/JS (без фреймворков)
- **Тестирование**: Node.js test runner

## 🚀 Быстрый старт
